# Applitools MCP Server

This repository holds the MCP Registry manifest (`server.json`) for the Applitools MCP server (`io.github.applitools/applitools`). The server's source code is not hosted here.

- Install and usage: [`@applitools/mcp` on npm](https://www.npmjs.com/package/@applitools/mcp)
- Documentation: [Applitools MCP server docs](https://applitools.com/docs/eyes/integrations/mcp-servers/applitools-mcp)
- Support: [Contact Applitools Support](https://help.applitools.com/hc/en-us/requests/new)

`server.json` is copied from the `@applitools/mcp` npm package by `.github/workflows/publish-mcp-registry.yml` after each release is published to the MCP Registry; do not edit it by hand.
